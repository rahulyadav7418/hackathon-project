# Offer Management System 

A simple full stack web application built using:

- Node.js
- Express.js
- MongoDB
- EJS
- CSS

## Features
- Create offers
- Edit offers
- Delete offers
- View all offers

## Teck Stack
- backend: Node.js, Express.js
- Database: MongoDB
- Frontend: EJS, CSS
